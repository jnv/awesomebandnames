# Awesome Band Names

This is a free and open source list of awesome band names. You are free to use the names in this list for any purpose whatsoever.

Awesomeness of band names not guaranteed.

## What is this?

This is a project that @CheesyNach0 started for themselves - a list of all the phrases they read and said that made them think "Y'know, that'd be a good name for a band."

At some point the original repo was removed and @jnv ended up maintaining the only fork.

There are too many names where there is no way we'll ever be able to use all of these names in some kind of project. Thus, we turn them over to you. Use them wisely.

## How to add band names of your own

1. Fork this repository.
2. Add your band name as a bullet point in the band names list below. Keep the list in alphabetical order, ignoring a leading "The", and avoid duplicates.
3. Submit a pull request.
4. If the maintainers think your band names are sufficiently awesome to be added to the list, they will be.

For best results, add only one band name per pull request.
